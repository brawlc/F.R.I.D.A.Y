Local artifact: safe static evidence

Upload a file (up to 8 MB), state that you are authorized, then FRIDAY calculates a hash and stores isolated evidence. A restricted worker profiles it without executing it. You receive a Markdown/JSON report and an audit trail.

Profiles: format and strings, PE/ELF/Mach-O headers, classic PCAP metadata, or source architecture.
